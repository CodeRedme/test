# Upload SYSTEM ERROR to GitHub in three batches

1. Download the three part ZIPs.
2. Extract every part into the same empty folder. Keep the folder structure created by extraction; the parts contain different, non-overlapping files.
3. Upload the combined project contents to the root of one GitHub repository.
4. Enable GitHub Pages and open `index.html` from the published site.

The corrected project includes 21 games, world-specific character portraits, and the separate intro-only character art. Each part contains fewer than 100 files.
